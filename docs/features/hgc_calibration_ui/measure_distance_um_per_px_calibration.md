calibrate px per um:
operator clicks 'measure' on the calibration overlay ,
operator moves the cursor to the desired start location on the big live image
next to the cursor another small overlay appears (moves with the moving mouse cursor) with the text 'click to measure distance'  
operator clicks one point on the big live image ,
the clicked point is marked on the big live image 
operator moves mouse to the second desired measure point 
a line from first clicked point to mouse cursor is visualized
operator clicks second point
operator enters a value in mm in the cursor overlay

the values px per um or um per px are calculated automatically


the 'calibration' overlay does not show any image. the measuring has to be done on the big live image
